# Advogado em Boituva — Vieira & Marques

Landing page exportada do Claude Design (projeto "BOITUVA | LP - Vieira e Marques").

`index.html` é um bundle autocontido (CSS, JS, fontes e imagens embutidos). Para publicar,
envie todo o conteúdo desta pasta para a raiz do domínio
`https://boituva.vieiraemarquesadvogados.com/` (ex.: `public_html` na Hostinger).

- `uploads/16.jpg` — imagem usada em `og:image` / `twitter:image`
- `uploads/favicon/` e `favicon.ico` — ícones do site
- `robots.txt` e `sitemap.xml` — SEO
